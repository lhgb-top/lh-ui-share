## لمن هذا التوثيق

- **مطورو مكتبات واجهة المستخدم في كل طرف** (lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp): للاطلاع على توقيع كل دالة نقية وقيمتها المعادة وشروطها الحدية، وكيفية تجاوز رموز الأنماط.
- **المطورون المستقلون الذين يستخدمون share مباشرة**: المشاريع التي تريد خط أساس لإمكانية الوصول ورموز السمة بالنمط الصيني فقط، دون استيراد أي مكتبة واجهة.
- **المساهمون**: لفهم مسؤوليات الأدلة والخطوط الحمراء والتحقق وسير الإصدار.

## فهم هذه الحزمة في خمس دقائق

```md
- `src/core/<المكوّن>/`        —— منطق الدوال النقية (logic.ts / types.ts)، بلا استيراد لأي إطار عمل
- `src/core/shared/`          —— النواة المشتركة بين المكوّنات (popper / virtual / sx / keyboard …)
- `src/theme/`                —— جانب السمة بلغة TS: الأنواع + خمسة مسبقات إعداد + بدائيات وقت التشغيل
- `styles/`                   —— المصدر الوحيد لأنماط مكوّنات BEM + رموز theme/common/*.scss
- `src/{constants,locales,types,utils}/` —— الثوابت / حزم اللغة / الأنواع / الأدوات
```

الخطوة التالية: ابدأ بـ [البدء](/ar/guide/getting-started) لتثبيت الحزمة واستيراد الأنماط؛ أو اطلع مباشرة على [مداخل الحزمة والمسارات الفرعية](/ar/guide/exports) لمعرفة كيفية الاستيراد عند الطلب.
