`styles/` هو **المصدر الوحيد** لأنماط مكوّنات العائلة بصيغة BEM
([الخط الأحمر 2](/ar/development/contribution#الخطوط-الحمراء-الستة)): 58 دليل مكوّن +
طبقة الرموز `theme/common/`. ولا يُسمح لأي مكتبة واجهة بنسخ الأنماط وتعديلها يدويًا.

## بنية الدليل

```
styles/
├── index.scss                  # التجميع الكامل (الرموز + كل المكوّنات)، استيراد بسطر واحد
├── theme/
│   ├── common/
│   │   ├── var.scss            # رموز الوضع الفاتح (:root، 185 متغير CSS)
│   │   ├── var-dark.scss       # تجاوزات الوضع الداكن ([data-theme='dark'], .dark، 118 عنصرًا)
│   │   ├── variables.scss      # طبقة متغيرات SCSS (183 متغيرًا $lh-*، ثوابت في وقت الترجمة)
│   │   ├── patterns.scss       # نظام الزخارف الصينية (6 زخارف)
│   │   ├── transition.scss     # المصدر الوحيد لأسماء أصناف الانتقال عبر الأطراف (3 mixin)
│   │   └── …                   # طبقة mixin / function العامة
│   └── index.scss              # مدخل تجميع السمة
├── button/index.scss           # أنماط المكوّن (58 دليلًا)
├── dialog/index.scss
└── …
```

**كل دليل مكوّن هو ملف `index.scss` واحد**، يُستورد عبر `@lh-ui/share/styles/<name>`
(يحلّ vite الدليل إلى index).

## طريقة الاستيراد

```ts
// أربع طرق للاستيراد (انظر البدء)
import '@lh-ui/share/styles/button'        // مكوّن واحد
import '@lh-ui/share/styles'                // الكل (styles/index.scss)
import '@lh-ui/share/styles/theme'          // رموز السمة فقط
import '@lh-ui/share/styles/theme/common/var-dark'  // وصول إلى ملف محدد
```

تختلف استراتيجية الحقن في كل مكتبة واجهة: يحقن plus كل الأنماط عند مدخل المكتبة، أما
vue2 فيستورد المستخدم عند الطلب (انظر [استراتيجية الحقن](/ar/guide/injection)).

## اتفاقيات BEM

تأخذ أسماء الأصناف دائمًا البادئة `lh-` + ثلاث طبقات من BEM:

```scss
.lh-button {                    // Block
  &__text { }                   // Element
  &--primary { }                // Modifier
  &__text--disabled { }         // Element + Modifier
  &.is-loading { }              // صنف الحالة (بادئة is-، دون نطاق تسمية)
}
```

- تُولَّد الأسماء بواسطة [createNamespace](/ar/reference/utils#createnamespace--نطاق-تسمية-bem)
  لضمان الاتساق في العائلة بأكملها.
- **أصناف الحالة تستخدم البادئة `is-`** (`is-loading` / `is-disabled` / `is-open`)،
  وليست معدِّلات BEM.
- عند إضافة أسماء أصناف جديدة يجب تحديث `docs/src/data/classes.json` (يُولَّد بواسطة
  `scripts/gen-docs-data.mjs` الذي يفحص `styles/*/index.scss`).

## ثلاث طبقات للرموز

| الطبقة | الملف | العدد | الخصائص |
| --- | --- | --- | --- |
| متغيرات CSS (فاتح) | `var.scss` | 185 عنصرًا | `:root { --lh-*: ... }`، يمكن تجاوزها في وقت التشغيل |
| متغيرات CSS (داكن) | `var-dark.scss` | 118 عنصرًا | `[data-theme='dark'], .dark { ... }` تجاوز الفاتح |
| متغيرات SCSS | `variables.scss` | 183 متغيرًا | `$lh-*`، **مخبوزة في وقت الترجمة** |

### لا تستهلك المكوّنات إلا متغيرات CSS

```scss
// ✅ صحيح: سلسلة fallback عبر var()، تُقيَّم في وقت التشغيل
.lh-button--primary {
  color: var(--lh-color-on-primary, #fff);
  background: var(--lh-primary-color, #1677ff);
}

// ❌ خطأ: الإشارة المباشرة إلى متغير SCSS، لن ينقلب في الوضع الداكن
.lh-button--primary {
  background: #{$lh-primary-color};
}
```

### فخ الخبز في وقت الترجمة

الرموز التي تأخذ في `var.scss` قيمًا بصيغة `#{$lh-foo}` تُستبدل متغيراتها SCSS في
**وقت الترجمة بقيم فاتحة ملموسة**، فلا تنقلب تلقائيًا في الوضع الداكن. ويجب أن تشير
هذه الرموز بشكل صريح من جديد إلى الرموز الدلالية الداكنة داخل `var-dark.scss`:

```scss
// var-dark.scss
[data-theme='dark'],
.dark {
  --lh-menu-item-color: var(--lh-text-primary);   // ← إعادة توجيه صريحة
}
```

أدّى مثل هذا النقص في السابق إلى بقاء نصوص القوائم / الجداول / الخطوط الزمنية تأخذ
قيمًا فاتحة فلا تظهر في الوضع الداكن. ويقوم على حراسة ذلك البند السابع من
`pnpm verify:styles` (إمكانية الوصول في الوضع الداكن). وفي المقابل فإن **سلسلة
fallback** `var(--lh-foo, var(--lh-bar, #x))` داخل المكوّن **تُقيَّم في وقت التشغيل**،
فتكون آمنة ما دام في السلسلة رمز لديه تجاوز داكن، دون الحاجة إلى إعادة التصريح.
لمزيد من التفاصيل انظر [الوضع الداكن](/ar/theme/dark-mode#فخ-الخبز-في-وقت-الترجمة).

## ملف `styles/index.scss` مُولَّد

ملف التجميع الكامل **يُولَّد بواسطة `scripts/build-styles.mjs`** عبر فحص أدلة المكوّنات،
ويتحقق `verify:styles` من اتساقه —— **لا تُعدِّله يدويًا**. وأي دليل مكوّن جديد يُغطَّى
تلقائيًا بالتجميع.

## ملاحظات

- **تعديل الأنماط يتم في هذا المستودع فقط**: لا يُسمح لأي مكتبة واجهة بإمساك نسخة من
  scss المكوّن. وتُستوعب اختلافات أسماء أصناف الانتقال عبر الأطراف بـ
  [transition mixin](/ar/reference/transition-mixins).
- **الألوان دائمًا `var(--lh-*, fallback)`**، ولا تُضاف قيم ألوان جامدة (يتولى حراستها
  بند var fallback في verify:styles).
- **يجب أن يملك المكوّن الجديد `styles/<name>/index.scss`**، وإلا فلن يكون له مخرجات
  أنماط في أحد الأطراف (تخطٍّ صامت في سكريبت البناء دون خطأ).
- **اكتمال الوضع الداكن شرط إلزامي**: تدعم جميع المكوّنات افتراضيًا الوضعين الفاتح
  والداكن، ويُعترض أي نقص في الوضع الداكن عبر البند السابع من verify:styles.
