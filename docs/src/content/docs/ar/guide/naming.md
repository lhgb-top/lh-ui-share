# اتفاقيات التسمية

تتوحّد اتفاقيات التسمية في العائلة بأكملها، بما يتوافق مع `docs/project/development-guide.md`
في مستودع plus.

## جذر النطاق العكسي

**`top.lhgb`** (كتابة عكسية لـ `www.lhgb.top`) هو جذر التسمية لجميع مستودعات عائلة lh-ui.

- **جانب JS / npm**: يبقى اسم الحزمة ضمن النطاق `@lh-ui/*` — لا تسمح أسماء حزم npm
  بالنقاط، فلا يمكن استخدام `top.lhgb` كاسم حزمة مباشرةً. وينحصر النطاق العكسي في
  **طبقة المعلومات الوصفية**: تُوحَّد `homepage` / `repository` / `author` في `package.json`
  على `lhgb.top`.
- **جانب الأطراف الأصلية**: تستخدم applicationId / bundleId / package في
  `lh-ui-android` / `lh-ui-ios` / `lh-ui-harmony` / `lh-ui-c` الصيغة `top.lhgb.*`
  (وهي خارج هذا المستودع).

## أربع درجات لبادئة LH

**يجب أن تحمل الرموز غير التابعة لجهات خارجية البادئة `LH`**، ويُلتزم بذلك عند إنشاء
ثابت / نوع / واجهة جديدة، دون تركها للتغيير الموحّد لاحقًا:

| الدرجة | الصيغة | أمثلة |
| --- | --- | --- |
| ثابت | `LH_XXX` (أحرف كبيرة مع شرطة سفلية) | `LH_SIZE_DEFAULT` و `LH_LANGUAGE_DEFAULT` و `LH_THEME_PRESETS` |
| نوع / واجهة | `LhXxx` (أحرف كبيرة البداية) | `LhThemePreset` و `LhSxProps` و `LhVirtualRange` |
| singleton على مستوى الوحدة / كائن بأحرف صغيرة | `lhXxx` (أحرف صغيرة البداية) | `lhlocale` |
| اسم صنف BEM / اسم المكوّن | `lh-xxx` / `LhXxx` | `.lh-button--primary` و `name: 'LhButton'` |

هيكل تسمية الثابت هو **`LH_<الوحدة>_<المفهوم>`**، ويلحق ثابت القيمة الافتراضية `DEFAULT`:

- `LH_DRAWER_DIRECTION_DEFAULT` (وليس `LH_DEFAULT_DRAWER_DIRECTION`)
- `LH_DROPDOWN_PLACEMENT_DEFAULT` و `LH_POPCONFIRM_TYPE_DEFAULT`

بما يتوافق مع `LH_SIZE_DEFAULT` / `LH_LANGUAGE_DEFAULT` الموجودة مسبقًا.

## تسجيل الإعفاءات

مصطلحات متفق عليها ولا تُجبَر على إضافة البادئة. **سجِّل السبب قبل أي تعديل**:

| الرمز | السبب |
| --- | --- |
| تصدير حزمة اللغة `zhCN` / `enUS` | تسمية locale قياسية، يُعاد تصديرها كواجهة برمجة تطبيقات عامة في `@lh-ui/vue3` / `@lh-ui/vue2` / uniapp، وتغيير الاسم له أثر كسر واسع |
| **قيمة النص** لاسم مسبق السمة (مثل `name: 'cerblue'`) | قيمة يكتبها المستخدم في `theme` الخاص بـ ConfigProvider، وتغييرها يكسر كل تكوينات المستهلكين؛ أما **معرّف TS** المقابل فيحمل البادئة (`LhCerblue`) |
| رموز التصدير لتبعيات الطرف الثالث (مثل الأدوات المستوردة بخلاف `deepMerge`) | غير إلزامي |

## تغييرات الأسماء في 0.4.0

قبل 0.4.0 لم يتابع هذا المستودع اتفاقية بادئة العائلة، وتم تدارك ذلك في هذا الإصدار من
جانبه. الكل عبارة عن استبدال آلي على مستوى المعرّفات، والجدول الكامل للتخطيط في
[دليل الترقية إلى 0.4.0](/ar/guide/migration-04).
