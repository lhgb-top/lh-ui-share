الرمز (token) هو تمثيل لغة التصميم في متغيرات: تُسمَّى الألوان وأحجام الخطوط والمسافات
وزوايا الاستدارة والظلال ومدد التحريك بمتغيرات CSS على الصيغة `--lh-*`، فيستهلك
المكوّن الأسماء فقط دون كتابة القيم حرفيًا. وتبديل السمة هو تبديل الرموز.

## ثلاث طبقات للرموز

| الطبقة | الموقع | العدد | وقت التقييم | القابلية للتجاوز |
| --- | --- | --- | --- | --- |
| متغيرات CSS · فاتح | `:root` في `styles/theme/common/var.scss` | **185 عنصرًا** | وقت التشغيل | ✅ تجاوز حر |
| متغيرات CSS · داكن | `[data-theme='dark'], .dark` في `styles/theme/common/var-dark.scss` | **118 عنصرًا** | وقت التشغيل | ✅ |
| متغيرات SCSS | `styles/theme/common/variables.scss` | **183 متغيرًا** | **وقت الترجمة** | ⚠️ لا يغيَّر إلا بتعديل المصدر وإعادة الترجمة |

### رموز الوضع الفاتح (var.scss)

```scss
:root {
  --lh-primary-color: #2B4C7C;
  --lh-text-primary: rgba(0, 0, 0, 0.88);
  --lh-bg-color: #FAF6F0;
  --lh-border-color: #e5e6eb;
  --lh-radius-base: 6px;
  --lh-spacing-base: 8px;
  // ... 185 عنصرًا
}
```

### تجاوزات الوضع الداكن (var-dark.scss)

```scss
[data-theme='dark'],
.dark {
  --lh-bg-color: #2A2520;
  --lh-text-primary: #E8E0D8;
  --lh-border-color: #3A3530;
  // ... 118 عنصرًا
}
```

الوضع الداكن **طبقة تجاوز** لا مجموعة مستقلة: تُكتب الـ 118 عنصرًا التي تحتاج إلى
الانقلاب فقط، ويُفرَض الباقي عن القيم الفاتحة.

### متغيرات SCSS (variables.scss)

```scss
$lh-primary-color: #2B4C7C !default;
$lh-border-radius-base: 6px !default;
// ... 183 متغيرًا
```

وظيفة متغيرات SCSS هي **المشاركة في حسابات وقت الترجمة**: مزج الألوان (`mix()` /
`shade()`)، وتركيب الظلال (جمع ظلال متعددة) — وهي أمور لا تقدر عليها متغيرات CSS.
وثمن ذلك **الخبز في وقت الترجمة** — فلا تنقلب تلقائيًا في الوضع الداكن.

## البنية الطبقية للرموز

للرموز ثلاث درجات، أولاهما في ملف السمة العام والثالثة في نمط كل مكوّن:

```scss
// 1. متغيرات SCSS (variables.scss، وقت الترجمة)
$lh-primary: #2B4C7C !default;
$lh-text-primary: #2C2C2C !default;

// 2. متغيرات CSS العامة (:root في var.scss، 190 عنصرًا)
--lh-primary-color: #{$lh-primary};
--lh-text-primary: #{$lh-text-primary};
--lh-bg-color: #FAF6F0;

// 3. متغيرات على مستوى المكوّن (في scss المكوّن، نطاقها جذر BEM للمكوّن)
.lh-card {
  --lh-card-bg: var(--lh-bg-color, #FAF6F0);
  --lh-card-border-radius: calc(var(--lh-border-radius-base, 2px) + 2px);
}
```

الآليات الرئيسية:

- **بين الدرجتين 1 و2 إقحام في وقت الترجمة، لا سلسلة إشارة `var()`**: تُخبَز قيمة
  `--lh-primary-color` من `$lh-primary` في وقت البناء، فلا فائدة من تغيير متغير SCSS
  في وقت التشغيل (بل تجب إعادة الترجمة). ولا توجد **طبقة وسيطة «لوحة ألوان أساسية»**
  في المشروع — فلا توجد متغيرات لسلالم الألوان مثل `--lh-blue-6`، وتُولَّد الرموز
  الدلالية مباشرةً من متغيرات SCSS.
- **نقطتا ارتكاز لتبديل السمة**: تغيير متغيرات SCSS في `variables.scss` وإعادة الترجمة
  (يؤثر في كل الرموز الدلالية)، أو تجاوز متغيرات CSS على `:root` في وقت التشغيل
  (وهو طريق `themeVars` في `ConfigProvider`، يفعّل فورًا).
- **تشير الدرجة الثالثة افتراضيًا إلى الدرجة الثانية**: تكون القيمة الافتراضية لمتغير
  المكوّن عادةً إشارة `var()` إلى الرمز العام (مع fallback)، فيحافظ على الارتباط مع
  السمة، ويتيح في الوقت نفسه تجاوز مكوّن واحد بشكل موجَّه عبر themeVars.

## المجالات الدلالية

المجالات الدلالية الرئيسية (التقسيم الكامل في جدول الرموز أدناه):

| المجال | رموز نموذجية | الاستخدام |
| --- | --- | --- |
| اللون الرئيسي | `--lh-primary-color` / `-hover` / `-active` / `-bg` / `-border` | خماسية اللون الرئيسي للعلامة |
| النص | `--lh-text-primary` / `-secondary` / `-tertiary` / `-disabled` | أربع مستويات لطبقة النص |
| الخلفية | `--lh-bg-color` / `-page` / `-secondary` / `-overlay` | الصفحة / الحاوية / الغطاء |
| الحدود | `--lh-border-color` / `-light` / `-dark` | الإطارات |
| الحالات | `--lh-success-color` / `-warning` / `-error` / `-danger` / `-info` | خمسة ألوان دلالية |
| زاوية الاستدارة | `--lh-radius-small` / `-base` / `-large` / `-circle` | أربع درجات لزوايا الاستدارة |
| المسافات | `--lh-spacing-*` | مقياس على أساس 8px |
| حجم الخط | `--lh-font-size-*` | سُلَّم أحجام الخطوط |
| الظل | `--lh-shadow-*` | مستويات الظل |
| التحريك | `--lh-animation-duration-*` / `-timing-function` | إيقاع الانتقالات |
| الزخرفة | `--lh-decoration-color` | لون الزخرفة الصينية |

## تجاوز الرموز

### في وقت التشغيل (موصى به)

```ts
// themeVars في ConfigProvider (تُضاف البادئة --lh- للمفاتيح المختصرة تلقائيًا)
<lh-config-provider :theme-vars="{ 'primary-color': '#1677ff' }">
```

أو كتابة CSS في مدخل التطبيق:

```css
:root {
  --lh-primary-color: #1677ff;
  --lh-primary-color-hover: #4096ff;
  --lh-primary-color-active: #0958d9;
}
```

لمزيد من التفاصيل انظر [التخصيص في وقت التشغيل](/ar/theme/customization).

### في وقت الترجمة (متغيرات SCSS)

```scss
// في scss مدخل المشروع، يُتجاوز قبل @use
$lh-primary-color: #1677ff;

@use '@lh-ui/share/styles';
```

دلالة `!default` هي «لا يُكتب فوقه إذا كان له قيمة"، فالإسناد قبل `@use` يكفي. **ملاحظة**:
يؤثر هذا في الجزء المخبوز في وقت الترجمة فقط، أما متغيرات CSS في وقت التشغيل
فتحتاج إلى تجاوز منفصل.

## الفجوات المعروفة في الرموز

لقد هبط «مشروع رموز الارتفاع» (إضافة `--lh-control-height-mini/small/medium/large/x-large`،
وتحويل button / select / input-number / cascader / tree-select / date-picker /
time-picker / input للاعتماد على الرموز، وتحويل input من الاشتقاق من padding إلى ارتفاع
ثابت، وإصلاح padding-top غير المتماثل للحقول ذات العنوان `padding-top: 16px`، وإزاحة
علامة الصح الثابتة في checkbox، وتكرار الترميز الجامد `translate(-50%,-50%)` في switch
معًا). وما يزال معلقًا:

1. عدم اتساق درجات الحجم بين spinner وicon (small 16 مقابل 14، medium 24 مقابل 16،
   إلخ). وتغيير أي جانب يمتد لكل المكتبة (message / notification / loading / جميع
   الأيقونات)، وشرط إطلاقه: شكوى بصرية حول خلط LhIcon / LhSpinner في المنفذ نفسه،
   وحينها يُفتح مشروع مستقل.
2. درجات size غير موزونة: select / switch بثلاث درجات فقط، وضيِّق validator في
   date / time-picker، وtree-select / rate / segmented / pagination بلا size،
   و mini و x-large بالكاد رُسِما في طبقة CSS (x-large موجود فقط في avatar في
   المكتبة بأكملها). وهذا تغيير في طبقة API، مفكوك الارتباط مع رموز الارتفاع.

## ملاحظات

- **لا يُصرَّح للمكوّنات بتعريف `--lh-*` بأنفسها**: لا تستهلك إلا عبر `var(--lh-*, fallback)`
  (خط أحمر في AGENTS.md الجذري). وتُضاف الرموز الجديدة في `var.scss`.
- **يجب كتابة fallback**: `var(--lh-primary-color, #1677ff)` — فعند غياب الرمز تبقى
  قيمة افتراضية مقبولة، ويتولى حراسة ذلك البند الثاني من `verify:styles` (var fallback).
- **اكتمال الوضع الداكن**: اسأل عند إضافة رمز «هل يجب أن ينقلب في الوضع الداكن؟»،
  فإن نعم فأضِف تجاوزًا في `var-dark.scss`، ويتولى حراسته البند السابع من verify:styles.
- **الرموز ذات القيم `#{$lh-foo}` مخبوزة في وقت الترجمة**: لا تنقلب تلقائيًا في الوضع
  الداكن، ويجب إعادة توجيهها صراحةً (لمزيد من التفاصيل انظر
  [الوضع الداكن](/ar/theme/dark-mode#فخ-الخبز-في-وقت-الترجمة)).
