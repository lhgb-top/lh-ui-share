## À qui s'adresse cette documentation

- **Aux développeurs des bibliothèques UI de chaque plateforme** (lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp) : pour consulter la signature, la valeur de retour et les limites de chaque fonction pure, ainsi que la façon de surcharger les jetons de styles.
- **Aux développeurs indépendants qui utilisent share directement** : le projet ne veut que la base d'accessibilité + les jetons du thème style chinois, sans aucune bibliothèque UI.
- **Aux contributeurs** : pour comprendre les responsabilités des répertoires, les lignes rouges, ainsi que les processus de vérification et de release.

## Ce package en cinq minutes

```md
- `src/core/<composant>/`   — logique en fonctions pures (logic.ts / types.ts), zéro import de framework
- `src/core/shared/`        — noyau partagé entre composants (popper / virtual / sx / keyboard …)
- `src/theme/`              — côté TS du thème : types + cinq préréglages + primitives d'exécution
- `styles/`                 — unique source des styles BEM des composants + jetons theme/common/*.scss
- `src/{constants,locales,types,utils}/` — constantes / paquets de langues / types / utilitaires
```

Prochaine étape : [Démarrage](/fr/guide/getting-started) pour installer le package et importer les styles ; ou consultez directement [les entrées du package et les sous-chemins](/fr/guide/exports) pour comprendre comment importer à la demande.
