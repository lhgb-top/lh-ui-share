Пять встроенных пресетов — это предлагаемое по умолчанию эстетическое решение lh-ui: каждый берёт основной цвет из традиционной китайской палитры и дополняет его полным набором светлой и тёмной цветовых схем.

## vars каждого пресета

### Пять базовых ключей (есть у всех пресетов)

```ts
{
  '--lh-primary-color': '...',
  '--lh-primary-color-hover': '...',
  '--lh-primary-color-active': '...',
  '--lh-primary-color-bg': '...',
  '--lh-primary-color-border': '...',
}
```

### Два дополнительных ключа у пресетов со светлым основным цветом

`songhua` (松花绿 (зелёный сосны)) и `golden` (藤黄 (gamboge)) — **светлоосновные**; контрастность белого текста на них не дотягивает до AA, поэтому для них обязательно добавить ещё два ключа:

| Ключ | Назначение |
| --- | --- |
| `--lh-color-on-primary` | Цвет текста на кнопке основного цвета (для светлого основного цвета используется чёрный) |
| `--lh-selected-color` | Цвет текста выделенного пункта (контрастность активного цвета в качестве текста на фоне при наведении недостаточна — цвет отдельно затемняется) |

**Почему это необходимо**: светлоосновная кнопка с белым текстом даёт контрастность всего 3.x:1, что не достигает AA 4.5:1. Гейт `verify:theme` это пресечёт.

Пример с 松花绿 (зелёный сосны): в комментариях к исходному коду зафиксированы причины исправлений:

- `--lh-color-on-primary`: 松花绿 (зелёный сосны) — светлый основной цвет, контрастность белого текста всего 3.93:1; чёрный текст даёт 4.73:1
- `--lh-selected-color`: активный цвет в качестве текста на фоне при наведении даёт всего 3.48:1, для выделенного пункта цвет затемняется отдельно (на цвет фона активной кнопки это не влияет)
- `--lh-primary-color-active`: исходный `#4B7A4A` давал 3.70:1 → `#4F8F4C` даёт 4.75:1

Для 藤黄 (gamboge) аналогично: белый текст 3.25:1 → чёрный текст 5.31:1; текст выделения 3.41:1 → затемнён до `#82600A`; active `#9A7208` 3.94:1 → `#A87F0A` 4.70:1.

**Жёсткое требование при добавлении нового пресета со светлым основным цветом**: обязательно задаются `--lh-color-on-primary` и `--lh-selected-color`, иначе гейт AA 4.5:1 в `verify:theme` завершится неудачей.

## Использование пресетов

### Получение пресета

```ts
import { LH_THEME_PRESETS, getThemePreset, getThemeVars } from '@lh-ui/share/theme'

LH_THEME_PRESETS                       // Все пять
getThemePreset('cerblue')              // Объект LhCerblue
getThemePreset('not-exists')           // undefined
getThemeVars('cerblue')?.['--lh-primary-color']
```

### Инъекция пресета (слой UI)

```ts
import { buildPresetStyleText, LH_PRESET_THEME_STYLE_ID } from '@lh-ui/share/theme'

function applyPreset(name: LhThemePresetName) {
  const vars = getThemeVars(name)
  if (!vars) return

  const text = buildPresetStyleText(vars)
  let style = document.getElementById(LH_PRESET_THEME_STYLE_ID)
  if (!style) {
    style = document.createElement('style')
    style.id = LH_PRESET_THEME_STYLE_ID
    document.head.appendChild(style)
  }
  style.textContent = text     // Заменяет, а не дописывает: при переключении темы старые пользовательские стили не остаются
}
```

**Ключевые моменты** (см. [ограничение инъекции в обзоре системы тем](/ru/theme/overview#ограничение-инъекции-писать-только-style-не-встроенный-style)): создавать можно только элементы `<style>`, а не встроенный style на `documentElement` — иначе цветовая палитра тёмной темы исказится.

### ConfigProvider в UI-библиотеках

```vue
<!-- lh-ui-plus / lh-ui-vue2 -->
<lh-config-provider theme="cerblue">
  <App />
</lh-config-provider>
```

Prop `theme` принимает `LhThemePresetName`, а внутри компонента выполняется описанная выше логика инъекции. Страница настройки темы и ThemeStudio на сайте docs проходят по `LH_THEME_PRESETS` и автоматически выводят все пресеты — **после добавления нового пресета страницы документации в библиотеках править вручную не нужно**.

## Пользовательские пресеты

```ts
import { registerTheme, getThemePreset } from '@lh-ui/share/theme'

registerTheme({
  name: 'my-brand',
  label: 'Брендовый цвет',
  labelEn: 'Brand',
  description: 'Основной брендовый цвет компании',
  vars: {
    '--lh-primary-color': '#722ED1',
    '--lh-primary-color-hover': '#9254DE',
    '--lh-primary-color-active': '#531DAB',
    '--lh-primary-color-bg': '#F9F0FF',
    '--lh-primary-color-border': '#D3ADF7',
    // Для светлоосновного пресета нужно добавить ещё два:
    // '--lh-color-on-primary': '#101410',
    // '--lh-selected-color': '#...',
  },
})

getThemePreset('my-brand')   // Зарегистрировали — можно использовать
```

Семантика `registerTheme`:

- **Одноимённое переопределение**: `registerTheme({ name: 'cerblue', ... })` **перекроет встроенный пресет 青花瓷 (сине-белый фарфор)** — это сделано осознанно, чтобы сторона бизнеса могла настроить тему по умолчанию, не трогая компоненты.
- **Новые имена добавляются в конец массива**: порядок `LH_THEME_PRESETS` — «пять встроенных + зарегистрированные».
- **Реестр — состояние уровня модуля**: импортировали — им пользуются; на всё приложение один экземпляр.

## Процесс добавления нового встроенного пресета

1. Добавить объект `LhThemePreset` в `src/theme/themes/index.ts` (как минимум пять `--lh-primary-*`; для пресета со светлым основным цветом обязательно добавить `--lh-color-on-primary` и `--lh-selected-color`).
2. Добавить в массив `LH_THEME_PRESETS` и дополнить имя в реэкспорте `src/theme/index.ts`.
3. Запустить `pnpm test` (в `theme.spec` есть регрессия согласованности пресетов) + `pnpm verify:theme` (гейт AA 4.5:1).
4. Приложить changeset; страница настройки темы в документации библиотеки автоматически выведет новый пресет.

**Важно**: vars служат только для потребления в runtime на JS; основной цвет, используемый в компонентных SCSS, по-прежнему находится в `styles/theme/common/variables.scss` — **при переопределении основного цвета встроенной темы менять нужно в двух местах** (в theme.spec есть регрессия).

## Соглашения об именовании

**Строковые значения** пресетов (`name: 'cerblue'`) — это конфигурационные значения, которые пользователи пишут в `theme` ConfigProvider; их изменение сломает все downstream-конфигурации — это один из пунктов [реестра исключений из правил именования](/ru/guide/naming#регистрация-исключений). Соответствующие **TS-идентификаторы** тем не менее несут префикс (`LhCerblue`).

## Примечания

- **Незарегистрированное имя возвращает `undefined`**: `getThemePreset` / `getThemeVars` не выбрасывают исключений — слою UI нужно не забывать проверять на пустоту.
- **`--lh-primary-color-active` и `--lh-selected-color` — разные вещи**: первый — это цвет фона нажатой кнопки, второй — **цвет текста** в списках / выделенных пунктах. В пресетах со светлым основным цветом контрастность активного цвета в качестве текста выделения недостаточна — именно поэтому нужен отдельный `--lh-selected-color`.
- **Тёмная тема пресетов с тёмным основным цветом осветляется автоматически**: `buildPresetDarkVars` определяет, что контрастность основного цвета относительно тёмного фона страницы `#1A1A2E` ниже 3, и осветляет его (см. [Обзор системы тем](/ru/theme/overview#выведение-тёмных-переменных-в-buildpresetdarkvars)).
