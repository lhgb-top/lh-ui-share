## Для кого эта документация

- **Разработчики UI-библиотек платформ** (lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp): разобраться в сигнатуре, возвращаемом значении и граничных условиях каждой чистой функции, а также в том, как переопределяются стилевые токены.
- **Самостоятельные разработчики, использующие share напрямую**: проекту нужен только baseline доступности и токены тем в китайском стиле, без подключения UI-библиотек.
- **Контрибьюторы**: разобраться в назначении каталогов, красных линиях, процессах проверки и выпуска релизов.

## Пакет за пять минут

```md
- `src/core/<компонент>/`     —— логика чистых функций (logic.ts / types.ts), без импорта фреймворков
- `src/core/shared/`          —— общее ядро компонентов (popper / virtual / sx / keyboard …)
- `src/theme/`                —— TS-сторона темы: типы + 5 пресетов + runtime-примитивы
- `styles/`                   —— единственный источник BEM-стиилей компонентов + токены theme/common/*.scss
- `src/{constants,locales,types,utils}/` —— константы / языковые пакеты / типы / утилиты
```

Следующий шаг: в разделе [Начало работы](/ru/guide/getting-started) установить пакет и подключить стили; или сразу перейти к [точке входа пакета и подпутям](/ru/guide/exports), чтобы разобраться с импортом по требованию.
