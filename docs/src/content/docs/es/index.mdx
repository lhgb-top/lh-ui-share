## Para quién es esta documentación

- **Desarrolladores de las bibliotecas UI de cada plataforma** (lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp): para consultar la firma, el valor de retorno y las reglas límite de cada función pura, y cómo sobrescribir los tokens de estilos.
- **Desarrolladores independientes que usan share directamente**: proyectos que solo quieren la línea base de accesibilidad y los tokens del tema de estilo chino, sin importar ninguna biblioteca UI.
- **Contribuyentes**: para entender las responsabilidades de cada directorio, las líneas rojas y el flujo de verificación y release.

## Entender este paquete en cinco minutos

```md
- `src/core/<componente>/`     —— lógica de funciones puras (logic.ts / types.ts), sin importaciones de framework
- `src/core/shared/`           —— núcleo compartido entre componentes (popper / virtual / sx / keyboard …)
- `src/theme/`                 —— lado TS del tema: tipos + cinco presets + primitivas en tiempo de ejecución
- `styles/`                    —— única fuente de estilos BEM de componentes + tokens de theme/common/*.scss
- `src/{constants,locales,types,utils}/` —— constantes / paquetes de idioma / tipos / utilidades
```

Próximo paso: instala el paquete e importa los estilos en [Primeros pasos](/es/guide/getting-started), o consulta directamente [Entradas del paquete y subrutas](/es/guide/exports) para entender cómo importar a demanda.
