## 這份文件是給誰看的

- **各端 UI 庫的開發者**（lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp）：查每個純函式的簽名、傳回值、邊界，以及樣式令牌怎麼覆蓋。
- **直接使用 share 的獨立開發者**：專案只想要無障礙基線 + 國風主題令牌，不引任何 UI 庫。
- **貢獻者**：了解目錄職責、紅線、驗證與發版流程。

## 五分鐘看懂這個套件

```md
- `src/core/<元件>/`     —— 純函式邏輯（logic.ts / types.ts），零框架匯入
- `src/core/shared/`     —— 跨元件共享核心（popper / virtual / sx / keyboard …）
- `src/theme/`           —— 主題 TS 側：類型 + 五個預設 + 執行時原語
- `styles/`              —— 元件 BEM 樣式唯一源 + theme/common/*.scss 令牌
- `src/{constants,locales,types,utils}/` —— 常數 / 語言包 / 類型 / 工具
```
