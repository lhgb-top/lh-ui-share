## Who this documentation is for

- **Developers of the UI libraries** (lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp): look up
  every pure function's signature, return value, and edge cases, and how to override style tokens.
- **Standalone developers using share directly**: your project wants the accessibility baseline
  and the theme tokens without pulling in any UI library.
- **Contributors**: understand the directory responsibilities, the red lines, and the verification
  and release process.

## Understand this package in five minutes

```md
- `src/core/<component>/`  —— pure-function logic (logic.ts / types.ts), zero framework imports
- `src/core/shared/`       —— cross-component shared kernel (popper / virtual / sx / keyboard …)
- `src/theme/`             —— theme TS side: types + five presets + runtime primitives
- `styles/`                —— the single source of component BEM styles + theme/common/*.scss tokens
- `src/{constants,locales,types,utils}/` —— constants / language packs / types / utilities
```
