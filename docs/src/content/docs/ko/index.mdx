## 이 문서의 독자

- **각 단말 UI 라이브러리의 개발자**(lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp): 각 순수 함수의 시그니처, 반환값, 경계 조건, 그리고 스타일 토큰의 덮어쓰기 방법을 조사하기 위해.
- **share를 직접 사용하는 독립 개발자**: 프로젝트에 접근성 기준선과 중국풍 테마 토큰만 필요하고, UI 라이브러리는 전혀 도입하지 않는 경우.
- **기여자**: 디렉터리 책임, 레드라인, 검증과 릴리스 흐름을 파악하기 위해.

## 5분 만에 이해하는 이 패키지

```md
- `src/core/<컴포넌트>/` —— 순수 함수 논리(logic.ts / types.ts), 프레임워크 import 없음
- `src/core/shared/`           —— 컴포넌트 횡단 공유 코어(popper / virtual / sx / keyboard …)
- `src/theme/`                 —— 테마 TS 측: 타입 + 5개 프리셋 + 런타임 원시
- `styles/`                    —— 컴포넌트 BEM 스타일 유일 소스 + theme/common/*.scss 토큰
- `src/{constants,locales,types,utils}/` —— 상수 / 언어 팩 / 타입 / 유틸리티
```
