## このドキュメントの読者

- **各端 UI ライブラリの開発者**（lh-ui-plus / lh-ui-vue2 / lh-ui-react / lh-ui-uniapp）：各純関数のシグネチャ、戻り値、境界条件、そしてスタイルトークンの上書き方法を調べるため。
- **share を直接使う独立開発者**：プロジェクトにアクセシビリティのベースラインと中華風テーマのトークンだけが欲しく、UI ライブラリは一切導入しない場合。
- **コントリビューター**：ディレクトリの責務、レッドライン、検証とリリースの流れを把握するため。

## 5 分でわかるこのパッケージ

```md
- `src/core/<コンポーネント>/` —— 純関数ロジック（logic.ts / types.ts）、フレームワークインポートなし
- `src/core/shared/`           —— コンポーネント横断の共有コア（popper / virtual / sx / keyboard …）
- `src/theme/`                 —— テーマ TS 側：型 + 5 つのプリセット + ランタイムプリミティブ
- `styles/`                    —— コンポーネント BEM スタイルの唯一ソース + theme/common/*.scss トークン
- `src/{constants,locales,types,utils}/` —— 定数 / 言語パック / 型 / ユーティリティ
```
